# 🚀 React + Firebase CRUD

Projeto desenvolvido com React.js e Firebase, contendo autenticação de usuários e CRUD completo com Firestore Database.

---

# 🛠️ Tecnologias

* React.js
* Firebase
* JavaScript
* HTML5
* CSS3

---

# 🔥 Funcionalidades

* ✅ Criar usuário
* ✅ Fazer login
* ✅ Logout
* ✅ Criar posts
* ✅ Listar posts
* ✅ Atualizar posts
* ✅ Excluir posts
* ✅ Dados em tempo real com Firestore

---

# 📂 Estrutura

```bash
src/
├── App.js
├── app.css
├── firebaseConnection.js
└── index.js
```

---

# ⚙️ Configuração Firebase

Crie um projeto no Firebase e ative:

* Authentication
* Firestore Database

Depois configure o arquivo:

```js
firebaseConnection.js
```

---

# ▶️ Executar Projeto

## Clonar repositório

```bash
git clone https://github.com/DevNelson16/React-Firebase-CRUD
```

## Instalar dependências

```bash
npm install
```

## Rodar projeto

```bash
npm start
```

---

# 📦 Instalar Firebase

```bash
npm install firebase
```
